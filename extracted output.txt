
Text: Transformers in Deep Learning

An Overview of Architecture, Scale, and Performance

The Transformer architecture, introduced in 2017, replaced recurrence with a self-attention mechanism that
lets a model weigh the relevance of every token in a sequence against every other token simultaneously.
This design enabled far greater parallelization during training than recurrent networks, and it has become
the foundation for nearly all modern large language models, from BERT and GPT to multimodal systems.

This report walks through the core architecture, compares parameter scale across notable models,
summarizes typical hyperparameters, and shows illustrative training behavior. Note: the training-loss curve
and parameter figures below are simplified, illustrative examples meant to convey general trends rather
than exact published benchmarks.

1. Core Architecture

A standard Transformer encoder block stacks a multi-head self-attention layer and a position-wise
feed-forward network, each wrapped with a residual connection and layer normalization. Positional
encodings are added to the input embeddings up front, since the attention mechanism itself has no inherent
sense of token order.

Text: Key components:

• Self-Attention: computes a weighted combination of all token representations, where weights reflect
learned relevance between tokens.

• Multi-Head Attention: runs several attention operations in parallel on different learned projections,
then concatenates the results.

• Feed-Forward Network: a position-wise fully connected network applied identically to each token.

• Residual Connections & Layer Norm: stabilize training and allow deeper stacks of layers.

4. Summary

Transformers have become the dominant architecture in deep learning largely because self-attention scales
well with data and compute, parallelizes efficiently on modern hardware, and captures long-range
dependencies more directly than earlier recurrent approaches. As the comparison above suggests, the
field's progress has closely tracked increases in model scale, though architecture and training-technique
improvements matter as well.
